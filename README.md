# ViteComm

ViteComm est une application de commerce électronique moderne conçue pour connecter les clients, les vendeurs et les livreurs de manière fluide et efficace.

## Structure du Projet

- **`frontend/`** : L'application web interactive développée avec React et Vite.
- **`model/`** : La documentation de l'architecture, le modèle logique des données (MLD) et les diagrammes UML (cas d'utilisation, classes, activités).

## Fonctionnalités Principales

- **Authentification & Rôles** : Inscription et connexion pour les clients, vendeurs, livreurs et administrateurs.
- **Gestion du Panier** : Sélection et ajout de produits au panier en temps réel.
- **Sélection du Livreur** : Choix flexible et transparent du livreur par le client.
- **Suivi des Commandes** : Suivi en temps réel de l'état de livraison de la commande.
